# destiny-1-decomp

Decompilation and native PC port of Destiny (PS4, CUSA00219, patch 01.33).

- **`analysis/`** has the whole executable analysed with Ghidra: every function, its pseudocode and
  disassembly, imports, strings and call graph. Generated by CI; see [docs/ghidra-pipeline.md](docs/ghidra-pipeline.md).
- **`native/`** is `d1-native`, which runs the original executable on Windows and Linux with a native Vulkan
  renderer. **`backend/`** is `d1-backend`, which stands in for Bungie's servers. Build and run instructions
  are in [native/README.md](native/README.md).
- **`records/`** and **`src/`** hold the decompilation itself: what each identified function is, and the
  reconstructed source as it is written.

[STATUS.md](STATUS.md) shows progress. [AGENTS.md](AGENTS.md) has the rules and layout.
[docs/roadmap.md](docs/roadmap.md) says what is next.

No game files are in this repository. You need your own copy of the game.
